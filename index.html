ANÁLISIS DE CONCURRENCIA

Este simulador representa un sistema multiprocesador donde cinco cores compiten por recursos compartidos de memoria. El comportamiento permite visualizar conceptos fundamentales de sistemas operativos y programación concurrente.

En el escenario de Deadlock, cada proceso adquiere un recurso y posteriormente solicita otro recurso que está siendo utilizado por otro proceso. Esta situación produce una espera circular, provocando que ninguno de los procesos pueda continuar.

En el escenario Mutex, se introduce una estrategia de arbitraje que modifica el orden de adquisición de recursos. Al romper la simetría se evita la formación de una cadena circular de espera.

GLOSARIO

DEADLOCK
Situación en la que varios procesos quedan bloqueados esperando recursos que otros procesos mantienen ocupados.
MUTEX
Mecanismo de exclusión mutua utilizado para controlar el acceso simultáneo a un recurso.
SECCIÓN CRÍTICA
Fragmento de código que accede a recursos compartidos y debe ejecutarse de manera controlada.
ESPERA CIRCULAR
Cadena donde cada proceso espera un recurso retenido por el siguiente proceso.
CORE
Unidad de procesamiento capaz de ejecutar instrucciones de manera independiente.
RAM
Memoria de acceso aleatorio utilizada por los procesos para almacenar temporalmente información.
