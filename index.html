CONCURRENCIA // MODELO TEÓRICO

La concurrencia ocurre cuando múltiples procesos o hilos ejecutan tareas de manera simultánea o intercalada y necesitan acceder a recursos compartidos.

En este laboratorio, los cinco núcleos representan procesos concurrentes y los cinco canales de RAM representan recursos compartidos. Cada proceso necesita dos recursos para entrar en su sección crítica.

CONCEPTO SIMULADOR FUNCIÓN
Proceso Core Entidad que solicita recursos
Recurso Canal RAM Elemento compartido
Sección crítica Procesamiento Acceso exclusivo a recursos
Mutex Bloqueo Control de acceso
Deadlock Interbloqueo Procesos esperando indefinidamente

GLOSARIO // INTERACTIVE

MUTEX
Mecanismo de exclusión mutua que permite que solamente un proceso acceda a un recurso.
DEADLOCK
Situación donde varios procesos esperan recursos retenidos por otros procesos.
ESPERA CIRCULAR
Cadena de procesos donde cada uno espera un recurso retenido por el siguiente.
RECURSO COMPARTIDO
Elemento utilizado por múltiples procesos que requiere sincronización.
SECCIÓN CRÍTICA
Parte del programa donde se accede a recursos compartidos y debe existir control de concurrencia.
